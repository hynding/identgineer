# CMS

The content management system for Identgineer will live here. It is generated by
[camis](https://github.com/hynding/camis) from a single content model, and runs as Strapi locally
and as strapi-php (camis' Filament target with `apiStyle: "strapi"`) on shared hosting.

The camis project is added in [Feature 7](https://github.com/hynding/identgineer/issues/7).
Generated output goes to `cms/generated`, which is git-ignored.
