# Variations in React

React needs nothing special: the variations are attributes on `<html>`, and
`@identgineer/variations` is a small framework-free runtime. Framework wrappers do not exist yet, so
this guide uses only what exists today: the attributes, the runtime and the
`<idg-variation-switcher>` custom element.

## 1. Attributes and the bootstrap script

Set the attributes on the root element and load the tokens. With Vite, put the bootstrap script
first in `index.html` (blocking, same origin, with its integrity; see
[plain-html.md](./plain-html.md)):

```html
<head>
  <script src="/variations/bootstrap.js" integrity="sha384-COPY-FROM-bootstrap.sri.json"></script>
  <link rel="stylesheet" href="/tokens/index.css" />
</head>
```

Without it, the first paint has the defaults and the visitor's choice arrives after React starts.

## 2. A hook for the state

`onVariationsChange` hears every change: yours, the switcher's, a script's and markup's. It is a
store that `useSyncExternalStore` takes directly. The snapshot must be the same object until
something changes, so it is cached.

```ts
// use-variations.ts
import { useCallback, useSyncExternalStore } from "react";
import {
  applyVariations,
  getVariations,
  onVariationsChange,
  resetVariations,
  shuffleVariations,
  type VariationState,
} from "@identgineer/variations";

let snapshot: VariationState | undefined;

function subscribe(notify: () => void): () => void {
  snapshot = getVariations();
  return onVariationsChange(({ state }) => {
    snapshot = state;
    notify();
  });
}

function getSnapshot(): VariationState {
  return (snapshot ??= getVariations());
}

// On the server there is no document: getVariations() returns the defaults. Cached, as React
// wants the same object each time.
let serverSnapshot: VariationState | undefined;

function getServerSnapshot(): VariationState {
  return (serverSnapshot ??= getVariations());
}

export function useVariations() {
  const state = useSyncExternalStore(subscribe, getSnapshot, getServerSnapshot);
  const apply = useCallback(
    (partial: Partial<VariationState>) => applyVariations(partial, { persist: true }),
    [],
  );
  const shuffle = useCallback(() => {
    // The four axes only, as the switcher does: the scheme is a preference, not a variation.
    const { theme, design, layout, ux } = shuffleVariations();
    return applyVariations({ theme, design, layout, ux }, { persist: true });
  }, []);
  const reset = useCallback(() => resetVariations({ persist: true }), []);
  return { state, apply, shuffle, reset };
}
```

`applyVariations` validates everything (an unknown value is left out and listed in `rejected`; it
never throws), so a value from a `<select>` or a prop can be passed as it is.

```tsx
import { REGISTRY } from "@identgineer/variations";
import { useVariations } from "./use-variations";

export function ThemePicker() {
  const { state, apply } = useVariations();
  return (
    <label>
      Theme
      <select
        value={state.theme}
        onChange={(event) => apply({ theme: event.target.value as typeof state.theme })}
      >
        {REGISTRY.theme.variations.map((theme) => (
          <option key={theme.id} value={theme.id}>
            {theme.label}
          </option>
        ))}
      </select>
    </label>
  );
}
```

## 3. The switcher as a custom element

Register the components once, on the client:

```tsx
// main.tsx
import { defineCustomElements } from "@identgineer/components/loader";

void defineCustomElements();
```

Declare the element for TypeScript, then use it. `Components.IdgVariationSwitcher` is generated by
the components package.

```tsx
// idg-variation-switcher.d.ts
import type { Components } from "@identgineer/components";
import type { DetailedHTMLProps, HTMLAttributes } from "react";

type SwitcherProps = Partial<
  Pick<Components.IdgVariationSwitcher, "axes" | "heading" | "orientation" | "persist">
>;

declare module "react" {
  namespace JSX {
    interface IntrinsicElements {
      "idg-variation-switcher": DetailedHTMLProps<HTMLAttributes<HTMLElement>, HTMLElement> &
        SwitcherProps;
    }
  }
}
```

Listen to `idgVariationsChange` with a ref and `addEventListener`, which works in every React
version (custom events are not part of React's synthetic events before 19):

```tsx
import { useEffect, useRef } from "react";
import type { VariationsChangeDetail } from "@identgineer/components";

export function Appearance({ onChange }: { onChange?: (detail: VariationsChangeDetail) => void }) {
  const ref = useRef<HTMLElement>(null);
  useEffect(() => {
    const element = ref.current;
    if (!element || !onChange) return;
    const listener = (event: Event) =>
      onChange((event as CustomEvent<VariationsChangeDetail>).detail);
    element.addEventListener("idgVariationsChange", listener);
    return () => element.removeEventListener("idgVariationsChange", listener);
  }, [onChange]);
  return <idg-variation-switcher ref={ref} heading="Appearance" persist />;
}
```

`persist` is a boolean attribute. React 18 renders `persist` on a custom element as
`persist="true"`, which the element reads as true; React 19 sets it as a property.

The event fires only for a change the visitor makes through the panel. To follow every change, use
`useVariations()` above.

## 4. Server rendering (Next.js, Remix)

The runtime touches no DOM when imported, so it is safe to import on the server. There are two
ways to avoid the wrong first paint.

**Leave it to the bootstrap script.** Put the script tag first in the document head. The server
renders the defaults, the script (which blocks painting) applies the stored choice or a shared link
before anything is drawn, and React hydrates over attributes that are already right. React warns
when the attributes on `<html>` differ from the server's HTML, so add `suppressHydrationWarning`
to `<html>`.

```tsx
// app/layout.tsx (Next.js, App Router)
import { bootstrapScriptAttributes } from "@identgineer/variations/bootstrap-tag";

const bootstrap = bootstrapScriptAttributes("/variations/bootstrap.js");

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en" suppressHydrationWarning>
      <head>
        {/* A plain script tag: React must not move or defer it. */}
        <script src={bootstrap.src} integrity={bootstrap.integrity} />
        <link rel="stylesheet" href="/tokens/index.css" />
      </head>
      <body>{children}</body>
    </html>
  );
}
```

`/variations/bootstrap.js` is `dist/bootstrap.js` of the built variations package, copied to
`public/variations/`. `bootstrapScriptAttributes` hashes the same source, so keep the two from the
same version of the package.

**Render the attributes on the server from a cookie.** The runtime stores a choice in
`localStorage`, which a server cannot read, so write a cookie yourself when the state changes and
read it with the package's validators. Everything read from the cookie goes through
`decodeVariations`, which keeps only registry ids.

```ts
// variations-cookie.ts (client)
import { encodeVariations, onVariationsChange } from "@identgineer/variations";

export function keepVariationsInCookie(): () => void {
  return onVariationsChange(({ state }) => {
    document.cookie = `idg-variations=${encodeURIComponent(encodeVariations(state))}; path=/; max-age=31536000; samesite=lax`;
  });
}
```

```tsx
// app/layout.tsx (server)
import { cookies } from "next/headers";
import { decodeVariations } from "@identgineer/variations";

export default async function RootLayout({ children }: { children: React.ReactNode }) {
  const stored = (await cookies()).get("idg-variations")?.value ?? "";
  const choice = decodeVariations(new URLSearchParams(stored));
  return (
    <html
      lang="en"
      data-theme={choice.theme}
      data-design={choice.design}
      data-layout={choice.layout}
      data-ux={choice.ux}
      data-scheme={choice.scheme === "system" ? undefined : choice.scheme}
      suppressHydrationWarning
    >
      <body>{children}</body>
    </html>
  );
}
```

Call `keepVariationsInCookie()` once in a client component's `useEffect`. Keep the bootstrap script
too: it also applies a link someone shared. Mind that a cookie is sent with every request and
needs a consent decision where the law asks for one.

An undefined attribute is not rendered, so an axis the visitor never chose falls back to the
stylesheet default.
