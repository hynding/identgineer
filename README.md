# Identgineer

A full stack identity and tracking platform, built as a pnpm monorepo: Stencil.js web components and website, with a CMS generated by [camis](https://github.com/hynding/camis) (Strapi locally, strapi-php on shared hosting).

The build is tracked feature by feature in [GitHub Issues](https://github.com/hynding/identgineer/issues?q=label%3Afeature).
