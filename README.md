# Identgineer

A full stack identity and tracking platform, built as a pnpm monorepo.

- **Identity**: user accounts, sign-in and sessions.
- **Tracking**: privacy-first, consent-first analytics events.
- **UI**: Stencil.js web components (`idg-` prefix) and a Stencil website with a sandbox.
- **CMS**: generated by [camis](https://github.com/hynding/camis). Strapi locally, strapi-php
  (camis' Filament target with `apiStyle: "strapi"`) on shared hosting.

Built with HTML5, CSS3 design tokens and strict TypeScript.

## Variation axes

The UI has four independent, interchangeable axes. Each is set as an attribute on the root
element and takes one of eight values, so any combination can be mixed freely.

| Attribute     | Axis            |
| ------------- | --------------- |
| `data-theme`  | Color theme     |
| `data-design` | Design language |
| `data-layout` | Page layout     |
| `data-ux`     | UX mode         |

## Repository layout

```

packages/identity     Identity domain
packages/tracking     Tracking domain
apps/site             Project website and sandbox
cms/                  camis project (Strapi / strapi-php)
docs/PLAN.md          Feature plan and working process
```

## Prerequisites

- Node.js 22 or newer (see `.nvmrc`)
- pnpm 10 (pinned in `package.json` via `packageManager`; enable with `corepack enable`)

## Common commands

```sh
pnpm install       # install workspace dependencies
pnpm format        # format with Prettier (format:check to verify only)
pnpm lint          # ESLint with type-aware typescript-eslint
pnpm typecheck     # tsc across every workspace package
pnpm test          # Vitest
pnpm build         # build every package that defines a build script
```
