# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately through
[GitHub security advisories](https://github.com/hynding/identgineer/security/advisories/new).
Do not open a public issue or pull request for a suspected vulnerability.

Include the affected package, the version or commit, steps to reproduce, and the impact you
expect. You can expect an acknowledgement within a few days; fixes are coordinated with you
before any disclosure.

## Supported versions

The project is pre-release. Only the latest commit on `main` is supported.

## Scope

In scope: the code in this repository, including the identity and tracking domains, the web
components, the website and sandbox, the CMS configuration, and the CI and deployment setup.

Out of scope: vulnerabilities in third-party dependencies with no demonstrable impact on this
project (report those upstream), and issues that require an already compromised host or
browser.
