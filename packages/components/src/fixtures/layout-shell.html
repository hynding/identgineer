Why a shell

A page is more than its content. The landmarks, the skip link and the order a keyboard user meets things in belong to the shell, so that every layout gets them right and the page author writes them once.

Layouts only place regions on a grid. They never reorder the markup, so what a screen reader announces and what the Tab key reaches is the same in all eight, and each layout chooses a small, a medium and a large arrangement from the width of its own container.

Switching layout at run time keeps focus where it was and the page where it was scrolled, and a navigation that has collapsed hands focus to its toggle.
